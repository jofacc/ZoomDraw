# ZoomDraw

![version](https://img.shields.io/badge/version-3.0.0-blue) ![platform](https://img.shields.io/badge/platform-macOS%2013%2B-lightgrey) ![license](https://img.shields.io/badge/license-MIT-green)

一个轻量的 macOS 屏幕**放大 + 截图 + 录屏 + 标注 + 文件暂存 + 剪贴板历史 + 窗口预览**小工具。

- 菜单栏常驻，不占 Dock
- 全局快捷键，可在偏好设置中自定义
- 放大状态下左键单击暂停，自动启用画笔叠加标注
- 微信/企业微信式截图：窗口自动识别、放大镜取色、标注工具栏、一键复制/保存
- 区域录屏：暂停/继续、实时计时，导出 **MP4** 或 **GIF**
- 暂存板：跨应用搬运文件的中转站，拖入拖出、拉框多选、贴边自动收起
- 剪贴板历史：自动记录文本 / 链接 / 颜色 / 图片 / 文件，搜索、分类、预览、一键粘贴回原应用；同一输入框按 `⌘1`–`⌘9` 进行 AI 搜索、AI 指令（翻译 / 总结 / 识图…）或网页搜索
- 程序坞预览：鼠标停在程序坞图标上显示该应用所有窗口的缩略图，点击切换；`⌥Tab` 跨应用按窗口切换
- 原生 Swift + AppKit，单文件二进制 ~600 KB
- 支持 macOS 13+，已在 macOS 15 上测试

## 默认快捷键

| 操作 | 快捷键 |
|---|---|
| 开/关 **放大模式** | `⌥ A` |
| 开/关 **画笔标注** | `⌥ D` |
| **截图 / 录屏** | `⌥ S` |
| 开/关 **暂存板** | `⌥ V` |
| **剪贴板内容存入暂存板** | `⌥ ⇧ V` |
| 开/关 **剪贴板历史** | `⌘ \` |
| **窗口切换器** | `⌥ Tab` |
| 开/关 **程序坞预览** | 默认不设置 |

> 在菜单栏 → **偏好设置…**（`⌘,`）中自由修改；录制时按 `⌫` 可清除（不设置）。

### 放大模式
- 鼠标移动：跟随焦点
- 滚轮 / `+` `-`：调节倍率（1× – 8×）
- **鼠标左键单击**：暂停画面（自动进入画笔标注层）
- `ESC`：退出

### 放大暂停后（画笔叠加）
- `H` 或 `Tab`：隐藏 / 显示画笔层
- 鼠标拖拽：绘制
- 颜色：`1` 红 · `2` 黄 · `3` 绿 · `4` 蓝 · `5` 白
- 工具：`A` 自由 · `B` 矩形 · `C` 椭圆 · `D` 箭头
- 笔触：`[` 减小 / `]` 增大
- `Z` 撤销 · **`X` 清空当前画面**
- `ESC` 退出

### 截图
冻结全屏画面后进入选区模式：

- **拖动**框选任意区域；**单击**自动选中鼠标下最上层的可见窗口
- 选区阶段显示**放大镜**：像素级预览 + 坐标 + HEX 取色
- 选区确定后：拖动八向控制点微调，拖动选区内部整体移动
- **双击选区内部**：立即完成并复制到剪贴板
- 工具栏标注：

| 工具 | 键 |
|---|---|
| 矩形 | `B` |
| 椭圆 | `C` |
| 箭头 | `D` |
| 画笔 | `A` |
| 马赛克 | `M` |
| 文字 | `T` |

- 颜色 `1`–`6`（红/黄/绿/蓝/白/黑）；笔触 `[` / `]`
- `⌘Z` 撤销 · `⌘A` 全屏 · 右键返回重新框选 · `ESC` 退出
- **双击选区 / `⏎` / `⌘C` 完成并复制到剪贴板** · `⌘S` 保存为 PNG
- 文字输入：`⏎` 提交，`⇧⏎` 换行，`ESC` 取消

### 录屏
选区确认后，点击工具栏的**红色圆点**（或按 `⌘R`）开始录制当前选区：

- 录制区域外显示**红色虚线边框**，下方悬浮控制条
- 控制条：`暂停/继续`（`Space`）· `结束并导出`（`⏎`）· `取消`（`ESC`），可拖动位置
- 菜单栏图标变为红点，菜单中也可随时「结束并导出 / 取消录屏」
- 录屏中再次按 `⌥S` = 立即结束并导出
- ZoomDraw 自身的边框与控制条**不会被录进画面**
- 暂停时长不计入视频时间轴
- 导出时在保存面板的「文件格式」中选择：

| 格式 | 说明 |
|---|---|
| **MP4** | H.264 / 30 fps，原始 Retina 像素 |
| **GIF** | 自动降采样（≤900 px 宽、≤12 fps），循环播放 |

### 暂存板
在不同应用之间搬文件不用再「一手按住不能松」——先丢进暂存板，切好目标应用再拖出去。

- **拖入**：文件、文本、图片、网址都能接收
  - 文本 → `.txt`、图片 → `.png`、网址 → `.webloc`，自动落盘成真实文件
- **拖出**：从暂存板拖到任意应用（Finder、聊天窗口、上传框…），按「复制」语义，不会移动原文件
- **单击即可直接拖拽**：窗口未激活时第一次点击也直接作用于文件，不需要先点一下窗口
- **拉框多选**：空白处按住拖动框选，按 `⌘` / `⇧` 追加选择
- **拖动文件时自动浮现**（Yoink 风格），松手后若未使用会自动收起；可在偏好设置中关闭
- **贴边自动收起**：把窗口拖到屏幕左 / 右 / 上边缘，**松手即自动缩到边外**，只留一条彩色细条。点击细条（或按 `⌥V`）拉回；拖着文件靠近细条时会自动探出来接收
- **召唤后自动收回**：停靠状态下召唤出来，若鼠标离开板子且超过设定秒数（默认 3 秒）会自动缩回去；鼠标停在板子上不会收。可在偏好设置中改为 1/2/3/5/10 秒或关闭
- 停靠中按 `⌥V`：展开 → 再按一次立即收回
- 缩略图使用系统 QuickLook 预览，图片/PDF 能直接看到内容

| 操作 | 方式 |
|---|---|
| 打开 | 双击 / `⏎` |
| 多选 | `⌘` 点选 · 空白处拉框 · `⌘A` 全选 |
| 移除选中 | `Delete` |
| 复制到剪贴板 | `⌘C` |
| 从剪贴板存入 | `⌥⇧V`（全局）· `⌘V`（窗口内） |
| 在 Finder 中显示 | 右键菜单 |
| 清理失效条目 / 清空 | 右键菜单 · 标题栏垃圾桶 |

- 拖动标题栏移动窗口，右下角可调整大小，位置与尺寸会被记住
- 内容持久保存，重启应用后仍在（源文件被移动/删除的条目会标橙并可一键清理）

### 剪贴板历史
按 `⌘\` 在屏幕中央弹出历史面板，不会抢走当前应用的焦点，选中后直接粘贴回原来的输入位置。

- **自动记录**：文本（保留富文本格式）、链接、颜色值（`#RRGGBB`）、图片、文件
- **去重**：再次复制已有内容只会把它移到最前，不会重复
- **搜索**：打开即可输入，多个关键词用空格分隔；也会匹配来源应用名
- **分类**：全部 / 文本 / 图片 / 文件 / 链接 / 固定，`Tab` 切换
- **预览**：右侧显示全文、原图、文件缩略图，以及来源应用和复制时间
- **拖出**：条目可直接拖到其他应用

| 操作 | 按键 |
|---|---|
| 粘贴到当前应用 | `⏎` / 双击 |
| 以纯文本粘贴 | `⇧⏎` |
| 直接粘贴第 N 条 | `⌥1` – `⌥9` |
| **AI 搜索 / AI 指令 / 网页搜索**（见下） | `⌘1` – `⌘9` |
| 仅复制，不粘贴 | `⌘C` |
| 固定 / 取消固定（置顶、永不过期） | `⌘P` |
| 删除这一条 | `⌘⌫` |
| 存入暂存板 | `⌘S` |
| 打开（链接 / 文件 / 图片） | `⌘O` |
| 关闭 | `Esc` / 再按一次 `⌘\` |

- **隐私**：密码管理器标记为隐藏 / 临时的内容一律不记录；默认忽略钥匙串访问、密码、1Password、Bitwarden 等应用，可在设置中增删
- 菜单栏「剪贴板记录」可**暂停记录**（15 分钟 / 1 小时 / 直到恢复）或**清除最近 5 分钟 / 15 分钟 / 全部**
- 默认保留 200 条 / 1 个月，可在「偏好设置 → 剪贴板」中调整；数据只保存在本机 `~/Library/Application Support/ZoomDraw/`

> ⚠️ 「选中后自动粘贴」需要**辅助功能**权限（用于模拟 `⌘V`）：
> 系统设置 → 隐私与安全性 → 辅助功能 → 勾选 ZoomDraw。未授权时会退化为「已复制，请手动按 `⌘V`」。

#### AI 搜索与 AI 指令（3.0）
同样在剪贴板历史的输入框里使用，`⌘1`–`⌘9` 对应的模板分三种类型：**AI 搜索**、**AI 指令**、**网页**。

- **AI 搜索**（默认 `⌘1`）：先联网搜索（搜狗 / 360 / DuckDuckGo，只读取结果的标题和摘要，不打开网页），再由 AI 整理回答；回答带来源卡片和 `[1]` 角标，悬停看摘要、点击打开网页，末尾给出 3 个相关问题。搜索失败时自动改为直接回答，并提示「未联网，内容可能过时」
- **AI 指令**：把输入内容（或选中的条目全文）套进提示词发给 AI。默认启用 翻译 / 解释 / 总结 / 润色 / 识别图片，另预置 纠错、写成邮件、提取待办、帮我回复、起标题、解释代码、写正则、Excel 公式、终端命令
- **识图**：输入框为空、选中图片条目时按 AI 模板，图片会一起发给 AI（OCR、看图答题）
- 回答以 Markdown 渲染（标题、列表、表格、代码高亮 + 复制按钮、任务列表），自动适配深浅色；流式输出，`Esc` 随时停止
- 回答界面：`⏎` 追问（保留上下文）· 输入框为空时 `⏎` **粘贴回答回原应用** · `⇧⏎` 粘贴 Markdown · `⌘C` 复制（有选中文字时复制选中部分）· `⌘P` **钉住为独立窗口**（置顶，可继续追问）· `⌘R` 重新生成 · `⌘S` 存入暂存板 · `⌘1`–`⌘9` 用其他模板处理同一内容 · `Esc` 停止 / 返回列表
- **AI 历史**：分类栏「✦ AI 历史」，可搜索、`⏎` 打开继续追问、`⌥1`–`⌥9` 直接粘贴回答、`⌘⌫` 删除；可在设置中关闭或清空
- 「偏好设置 → AI」：使用任意 **OpenAI 兼容接口**（混元、DeepSeek、通义千问、Kimi、OpenAI …），填写接口地址、API Key、模型；支持获取模型列表、从 curl 命令导入、测试连接；思考模式（快速 / 深度 / 由模型决定）、搜索来源、参考网页条数
- **API Key 保存在系统钥匙串**，不会写入配置文件，也不在代码中；本项目不内置任何 Key

#### 网页搜索（参考 Alfred Web Search）
和剪贴板历史共用一个输入框，不需要新入口：

- 输入关键字后按 `⌘1` – `⌘9`，用对应的模板在浏览器中打开；面板底部会列出每个数字键对应的模板
- **输入框为空时**按 `⌘数字`，直接搜索当前选中的剪贴板条目（文本 / 链接 / 文件名，多行自动合并为一行）
- 关键字自动按 UTF-8 网址编码，中文、空格、`&`、`#` 都能正确处理；模板里已编码的部分（如 `%26`）原样保留
- 「偏好设置 → 快捷搜索」：勾选启用、改名、改网址、拖动排序（已勾选的前 9 个按顺序对应 `⌘1`–`⌘9`）、测试、恢复预置；可指定打开网页的浏览器
- 网址模板也可以是 `dict://`、`shortcuts://` 等链接，用来查系统词典或运行「快捷指令」，接入任意自定义流程
- 搜索内容不会写入剪贴板历史，也不保存搜索记录
- 面板打开期间会暂停 ZoomDraw 的其他全局快捷键（关闭后自动恢复），所以即使把 `⌘1` 等设成了全局快捷键，在面板里也照样用于网页搜索

默认模板（`{query}` 为输入内容）：

| 键 | 名称 | 类型 |
|---|---|---|
| `⌘1` | AI 搜索 | AI 搜索 |
| `⌘2` | 百度地图 | 网页 `http://map.baidu.com/?newmap=1&ie=utf-8&s=s%26wd%3D{query}` |
| `⌘3` | 翻译 | AI 指令 |
| `⌘4` | 解释 | AI 指令 |
| `⌘5` | 总结 | AI 指令 |
| `⌘6` | 润色 | AI 指令 |
| `⌘7` | 识别图片 | AI 指令 |

另预置（默认未勾选）：AI 指令 纠错 / 写成邮件 / 提取待办 / 帮我回复 / 起标题 / 解释代码 / 写正则 / Excel 公式 / 终端命令；网页 百度、Google、必应、知乎、哔哩哔哩、小红书、淘宝、有道词典、GitHub、京东、微信文章、豆瓣、维基百科、高德地图、YouTube、百度翻译、系统词典 `dict://{query}`、快捷指令示例 `shortcuts://run-shortcut?name=名称&input=text&text={query}`。

从 2.8 升级时：没改过模板的直接换成上面的新预置；改过的保留原有顺序和勾选，最前面加入「AI 搜索」并取消勾选百度，AI 指令补在后面（快捷键还有空位才勾选）。

### 程序坞预览
鼠标停在程序坞的应用图标上（默认 0.3 秒），在图标旁弹出该应用所有窗口的缩略图。

- **点击缩略图**切换到该窗口；最小化的窗口会先还原
- 窗口多时自动换行成网格；程序坞在左 / 右侧时预览显示在旁边
- 鼠标移到缩略图上显示 **关闭 / 最小化 / 全屏** 三个按钮；右上角「退出」退出整个应用
- 最小化 / 隐藏 / 其他桌面的窗口带标记；其他桌面的窗口点击后切到对应应用
- 鼠标进入预览后：`←` `→` `↑` `↓` 选择 · `⏎` 切换 · `ESC` 关闭
- 鼠标离开图标和预览约 0.2 秒后自动收起；不会抢走当前应用的焦点
- 「偏好设置 → 程序坞」：开关、悬停延迟（0.1 – 0.8 秒）、缩略图大小、是否显示最小化 / 其他桌面窗口 / 标题、不显示预览的应用
- 开启系统「台前调度」时自动暂停

### 窗口切换器
按住 `⌥` 连按 `Tab`，在所有应用的窗口之间切换（系统 `⌘Tab` 只能按应用切换）：

| 操作 | 按键 |
|---|---|
| 下一个 / 上一个 | `Tab` / `⇧Tab`、方向键 |
| 切换到选中窗口 | 松开 `⌥` / 鼠标点击 |
| 关闭窗口 | `W` |
| 最小化 / 还原 | `M` |
| 退出应用 | `Q` |
| 取消 | `ESC` |

- 按一下 `⌥Tab` 立即松开 = 在最近两个窗口之间来回切换
- 也可从菜单栏「窗口切换器」打开，此时用 `⏎` 确认

> ⚠️ 程序坞预览和窗口切换器需要**辅助功能**权限；缩略图显示窗口画面需要**屏幕录制**权限，未授权时显示应用图标。
> 如同时使用 iDock、DockDoor 等同类工具，请关闭其中一个的预览，避免重复弹出。

### 独立画笔标注
- 操作同上；`ESC` 退出

> ⚠️ 首次使用「放大 / 截图 / 录屏」时，macOS 会请求**屏幕录制**权限：
> 系统设置 → 隐私与安全性 → 屏幕录制 → 勾选 ZoomDraw → 重新启动应用。

```bash
bash build.sh
```
